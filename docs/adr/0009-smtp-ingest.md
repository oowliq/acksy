# ADR 0009. Приём уведомлений по SMTP

Принято 2026-11-10.

Приложения с почтовыми оповещениями могут публиковать уведомления в Acksy по SMTP. Процесс Acksy обслуживает отдельный порт с TLS с начала соединения по умолчанию. Для устройств в доверенной локальной сети оператор может явно включить `smtp.mode: plain` (`ACKSY_SMTP_MODE=plain`). Тогда сертификат и ключ не требуются, а API-токен и письмо передаются без шифрования. Адрес, домен получателей и файлы сертификата задаёт оператор при запуске. По умолчанию порт закрыт. Администратор включает приём писем в настройках интеграций согласно ADR 0008.

SMTP AUTH проверяет API-токен. Одна транзакция соответствует одной публикации. Имя получателя в настроенном домене определяет топик, а тема и текст письма — поля уведомления. Адаптер вызывает общий сервис публикации, который проверяет права, применяет лимиты и записывает уведомления получателей. Клиент получает подтверждение после завершения публикации.

HTTP-адаптеры остаются в реестре маршрутов. SMTP принимает соединения в жизненном цикле приложения и завершает их перед закрытием базы. Оператор может опубликовать SMTP-порт отдельно от HTTP и выдать клиенту токен с доступом к одному топику.
